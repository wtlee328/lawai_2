# LawAI 2.0 - 智慧法律文件生成平台

## 專案概述

LawAI 2.0 是一個先進的法律研究與文件生成平台，專為協助法律專業人士、研究人員和學生快速找到台灣司法系統相關法院判決並生成專業法律文件而設計。本平台結合AI驅動的案例搜尋與智慧文件生成功能，簡化整個法律研究與起草工作流程。

### 主要目標

- **簡化法律研究**：將複雜的法律案例搜尋轉化為簡單直觀的查詢
- **提升搜尋準確度**：運用AI理解搜尋的脈絡和含義，而非僅限於關鍵字匹配
- **自動化文件生成**：結合使用者輸入與相關案例先例生成專業法律文件
- **節省時間**：快速找到最相關的案例並生成文件，無需手動起草
- **強化分析能力**：提供案例內容、法律爭議、法院見解和判決結果的詳細洞察
- **支援多種搜尋方式**：提供簡單搜尋和進階多欄位搜尋，滿足不同研究需求
- **整合研究與起草**：無縫連接案例研究與文件生成工作流程

## 功能特色

### 1. 智慧搜尋引擎

**功能說明**：平台能夠理解您要尋找的內容，即使您沒有使用精確的法律術語。

**如何協助您**：
- 使用自然語言搜尋（例如：「涉及逾期付款的契約糾紛」）
- 找到具有相似法律概念的案例，即使使用不同的詞彙
- 根據與您特定查詢的相關性對結果進行排序

**範例**：如果您搜尋「房東房客問題」，系統會找到關於租賃糾紛、租約違約和物業管理問題的案例，即使這些確切詞彙並未出現在案例文件中。

### 2. 多欄位進階搜尋

**功能說明**：允許您同時搜尋法律案例的不同部分，獲得更精確的結果。

**可搜尋欄位**：
- **判決內容**：法院判決的完整文本
- **爭點**：主要爭議的法律問題
- **法院見解**：法官的推理和法律分析
- **判決結果**：最終結果和裁決

**如何協助您**：
- 針對對您研究最重要的案例特定方面
- 根據您的需求調整各欄位的重要性
- 透過專注於相關案例部分獲得更精確的結果

**範例**：在研究勞動法時，您可能會重視「爭點」以找到具有相似職場衝突的案例，同時如果您更關注法律論證而非結果，則給予「判決結果」較低的權重。

### 3. 智慧工作區管理

**功能說明**：將您的研究專案組織成獨立的工作區，保持搜尋和發現的有序性。

**主要功能**：
- 建立最多5個不同的研究專案（任務）
- 每個工作區自動儲存您的搜尋歷史
- 在專案間切換而不失去進度
- 追蹤您已審閱和加入研究的案例

**如何協助您**：
- 保持不同法律事務的分離和有序
- 從中斷處恢復研究
- 與同事或客戶分享特定工作區

**範例**：您可能有一個「契約法研究」工作區，另一個「勞動糾紛」工作區，以及第三個「財產權案例」工作區。

### 4. 全面案例分析

**功能說明**：以易於理解的格式提供每個案例的詳細資訊。

**提供資訊**：
- **案例摘要**：關鍵事實和背景
- **法律爭議**：主要爭議點
- **法院推理**：法官如何分析案例
- **最終判決**：法院的裁決及其原因
- **相關法條**：引用的特定法律條文
- **案例詳情**：法院名稱、日期、案號

**如何協助您**：
- 無需閱讀完整文件即可快速理解案例相關性
- 識別相似案例間的模式
- 找到特定的法律先例和引用

### 5. 相關性評分系統

**功能說明**：透過視覺指標顯示每個搜尋結果與您查詢的匹配程度。

**功能特色**：
- 每個案例的整體相關性百分比
- 不同案例部分的個別分數
- 便於掃描的色彩編碼指標
- 從最相關到最不相關的排序

**如何協助您**：
- 優先關注最相關的案例
- 理解為何選擇某些案例
- 對要詳細審閱的案例做出明智決定

### 6. 智慧文件生成

**功能說明**：結合您的輸入與選定的案例先例，自動生成專業法律文件。

**支援文件類型**：
- **起訴狀**：民事訴訟起始文件
- **答辯狀**：回應與辯護文件
- **上訴狀**：向上級法院提出的上訴文件
- **聲請狀**：各種法律聲請與申請

**輸入欄位**：
- **基本資料**：文件類型、案件編號、法院、日期
- **當事人資料**：原告/被告詳細資料、地址、身分證字號
- **案件內容**：案件標題、事實、法律依據、聲請事項
- **輔助證據**：選定的案例先例、附件

**如何協助您**：
- 自動生成專業法律文件
- 確保適當的法律格式和結構
- 無縫整合相關案例先例
- 節省數小時的手動文件起草時間

### 7. 整合研究到文件工作流程

**功能說明**：將案例搜尋結果直接連接到文件生成，提供無縫工作流程。

**主要功能**：
- **案例選擇**：從搜尋結果中將相關案例加入文件生成
- **資料完整性追蹤**：視覺指標顯示必要資訊狀態
- **即時預覽**：在輸入資料時查看文件生成準備狀態
- **浮動進度UI**：便利的進度追蹤，隨您工作移動

**如何協助您**：
- 簡化整個法律研究和起草流程
- 確保文件準備中不遺漏重要案例
- 維持研究發現與最終文件間的一致性

### 8. 搜尋歷史和進度追蹤

**功能說明**：自動追蹤您的所有搜尋和研究進度。

**功能特色**：
- 所有執行搜尋的完整歷史
- 每個查詢的儲存結果
- 搜尋期間的進度指標
- 重新訪問和精煉先前搜尋的能力
- 跨會話的案例選擇持久性

**如何協助您**：
- 在先前研究基礎上建構而不重新開始
- 追蹤您的研究方法
- 為法律摘要展示徹底的案例法審查
- 維持選定案例供文件生成使用

## 工作流程

### 開始使用

#### 步驟1：帳戶設定和登入
1. 使用電子郵件和密碼建立您的帳戶
2. 透過安全登入頁面登入平台
3. 您的個人儀表板將自動載入

#### 步驟2：建立您的第一個工作區
1. 系統自動建立您的第一個研究工作區
2. 給它一個有意義的名稱（例如：「契約糾紛研究」）
3. 您可以為不同專案建立最多5個不同的工作區

### 基本搜尋流程

#### 步驟3：選擇您的搜尋方式
**選項A：一般搜尋**
- 最適合：快速搜尋和一般研究
- 使用時機：您有直接的問題或主題
- 範例：「違約案例」

**選項B：多欄位搜尋**
- 最適合：需要精確度的詳細研究
- 使用時機：您需要專注於案例的特定方面
- 範例：搜尋勞動糾紛，您最關心法律論證

#### 步驟4：輸入您的搜尋查詢

**一般搜尋**：
1. 用自然語言輸入您的問題或主題
2. 點擊搜尋按鈕或按Enter鍵
3. 等待結果載入（通常10-30秒）

**多欄位搜尋**：
1. 切換到「多欄位搜尋」模式
2. 填入相關欄位：
   - **判決內容**：一般主題或關鍵字
   - **爭點**：您正在研究的特定法律問題
   - **法院見解**：您感興趣的法律推理類型
   - **判決結果**：您想找到的特定結果
3. 如需要可調整欄位權重（選擇性）
4. 點擊搜尋

#### 步驟5：檢視搜尋結果
1. 結果按相關性排序顯示
2. 每個結果顯示：
   - 案例標題和基本資訊
   - 相關性分數和指標
   - 重點的簡要摘要
   - 法院和日期資訊

#### 步驟6：分析個別案例
1. 點擊任何案例以檢視詳細資訊
2. 檢視組織化的部分：
   - **摘要**：案例的快速概覽
   - **爭點**：主要法律問題
   - **法院見解**：法官的推理
   - **判決結果**：最終裁決
   - **相關法條**：適用的法規

#### 步驟7：管理您的研究
1. 標記重要案例供您研究
2. 將相關案例加入您的文件生成佇列
3. 使用標籤系統在不同部分間切換
4. 使用工作區切換器在不同專案間移動

### 文件生成流程

#### 步驟8：選擇相關案例供文件生成
1. **檢視搜尋結果**：檢查透過搜尋找到的案例
2. **加入文件生成**：點擊「加入到文件生成」按鈕選擇相關案例
3. **案例管理**：選定的案例會出現在文件生成區域
4. **必要時移除**：移除不再相關的案例

#### 步驟9：完成文件資訊
1. **切換到輸入標籤**：點擊「輸入」標籤進入文件生成
2. **填寫基本資料**：
   - 文件類型（起訴狀、答辯狀、上訴狀、聲請狀）
   - 案件編號、法院、日期
3. **輸入當事人資料**：
   - 原告/聲請人詳細資料（姓名、身分證字號、地址）
   - 被告/相對人詳細資料（姓名、身分證字號、地址）
4. **描述案件內容**：
   - 案件標題和事實
   - 法律依據和相關法條
   - 具體聲請或請求事項
5. **檢視輔助資料**：
   - 選定的案例先例自動出現
   - 必要時新增其他附件

#### 步驟10：生成法律文件
1. **資料完整性檢查**：系統顯示哪些部分已完成
2. **生成文件**：當所有必要欄位填寫完成時點擊「生成文件」
3. **檢視生成的文件**：AI結合您的輸入與案例先例
4. **下載或複製**：儲存生成的文件供使用

### 進階功能

#### 精煉您的搜尋
1. **調整欄位權重**：在多欄位搜尋中，使用滑桿強調某些方面
2. **修改查詢**：根據初始結果編輯您的搜尋詞彙
3. **結合方法**：使用一次搜尋的洞察來指導另一次搜尋

#### 組織結果
1. **工作區管理**：將不同法律事務保持在獨立工作區中
2. **搜尋歷史**：檢視並建構在先前搜尋基礎上
3. **進度追蹤**：監控您的研究覆蓋範圍和完整性
4. **案例選擇管理**：追蹤哪些案例被選定供文件生成

#### 文件生成功能
1. **即時驗證**：系統在您輸入時檢查資料完整性
2. **浮動進度UI**：便利的進度指標隨您的工作移動
3. **案例整合**：選定的案例自動整合到文件中
4. **專業格式**：生成的文件遵循適當的法律格式標準

#### 品質保證
1. **相關性檢查**：使用評分系統驗證結果品質
2. **交叉參考**：比較相似案例以確保全面覆蓋
3. **文件記錄**：為法律摘要追蹤您的搜尋方法
4. **案例選擇檢視**：驗證選定的案例適合您的文件

## 研究情境範例

### 情境1：契約法研究
**情況**：律師需要找到關於涉及逾期付款罰金的契約違約案例。

**工作流程**：
1. 建立工作區：「契約違約研究」
2. 使用多欄位搜尋：
   - **爭點**：「逾期付款罰金契約違約」
   - **判決結果**：「損害賠償罰金條款」
3. 檢視相關性分數超過80%的前10個結果
4. 分析相似案例中的法院推理
5. 為法律摘要記錄發現

### 情境2：勞動法調查
**情況**：人力資源專業人員研究不當解僱先例。

**工作流程**：
1. 建立工作區：「勞動解僱案例」
2. 從一般搜尋開始：「不當解僱勞動」
3. 以專注於法院見解的多欄位搜尋精煉
4. 比較不同法院對相似情況的處理方式
5. 識別關鍵法律標準和要求

### 情境3：法律文件準備
**情況**：律師為契約糾紛案件準備民事起訴狀。

**工作流程**：
1. 建立工作區：「契約糾紛案件 - 客戶ABC」
2. 使用多欄位搜尋尋找相關的契約違約案例
3. 選擇3-5個最相關的先例案例供文件生成
4. 切換到文件生成標籤並填寫：
   - 文件類型：起訴狀
   - 客戶資訊作為原告
   - 對方當事人作為被告
   - 契約糾紛事實和法律依據
5. 生成整合案例先例的專業起訴狀
6. 檢視並下載最終文件

### 情境4：學術法律研究
**情況**：法律系學生撰寫關於財產權演變的論文。

**工作流程**：
1. 建立工作區：「財產權演變」
2. 在不同時期使用多次搜尋
3. 專注於法院見解以追蹤法律推理變化
4. 建立全面的案例資料庫
5. 分析隨時間的趨勢和發展

## 技術架構與資料流程

### 前端元件
- **WorkspaceView.vue** (`src/views/WorkspaceView.vue`)：主要應用程式介面，具有標籤導航
- **SearchModule.vue** (`src/components/SearchModule.vue`)：案例搜尋功能，支援雙模式
- **FormInput.vue** (`src/components/FormInput.vue`)：文件生成介面，具有資料輸入表單
- **LogDisplay.vue** (`src/components/LogDisplay.vue`)：即時搜尋進度追蹤

### 資料流程
1. **搜尋階段**：使用者查詢 → API呼叫 → 帶有相關性分數的搜尋結果
2. **選擇階段**：使用者選擇相關案例 → 資料庫更新`added_to_doc_gen`狀態
3. **輸入階段**：使用者填寫文件資訊 → 即時驗證和進度追蹤
4. **生成階段**：結合使用者輸入 + 選定案例 → LLM處理 → 生成文件

### 資料庫架構
- **tasks**：使用者工作區/專案，具有狀態追蹤
- **search_results**：搜尋查詢、結果和案例選擇狀態
- **case_2**：具有多欄位嵌入的法律案例資料庫

### 狀態管理
- **workspace.ts** (`src/store/workspace.ts`)：任務管理、搜尋持久性、案例選擇
- **auth.ts** (`src/store/auth.ts`)：使用者認證和會話管理

### API整合
- **多欄位搜尋**：`https://wtlee328-multi-field-search-api.hf.space/multi-field`
- **一般搜尋**：`https://wtlee328-multi-field-search-api.hf.space/new-search`
