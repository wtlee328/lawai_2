# LawAI 2.0 - Intelligent Legal Document Generation Platform

## Project Overview

LawAI 2.0 is an advanced legal research and document generation platform designed to help legal professionals, researchers, and students quickly find relevant court cases from Taiwan's judicial system and generate professional legal documents. The platform combines AI-powered case search with intelligent document generation, streamlining the entire legal research and drafting workflow.

### Main Goals

- **Simplify Legal Research**: Transform complex legal case searches into simple, intuitive queries
- **Improve Search Accuracy**: Use AI to understand the context and meaning of your searches, not just keywords
- **Automate Document Generation**: Generate professional legal documents by combining user input with relevant case precedents
- **Save Time**: Quickly find the most relevant cases and generate documents without manual drafting
- **Enhance Analysis**: Provide detailed insights into case content, legal disputes, court opinions, and outcomes
- **Support Multiple Search Methods**: Offer both simple searches and advanced multi-field searches for different research needs
- **Integrate Research with Drafting**: Seamlessly connect case research with document generation workflow

## Features / Functions

### 1. Intelligent Search Engine

**What it does**: The platform can understand what you're looking for, even if you don't use exact legal terminology.

**How it helps**:
- Search using natural language (e.g., "contract disputes involving late payments")
- Find cases with similar legal concepts, even if they use different words
- Get results ranked by relevance to your specific query

**Example**: If you search for "landlord tenant problems," the system will find cases about rental disputes, lease violations, and property management issues, even if those exact words aren't in the case documents.

### 2. Multi-Field Advanced Search

**What it does**: Allows you to search across different parts of legal cases simultaneously for more precise results.

**Search Fields Available**:
- **Case Content** (判決內容): The full text of the court decision
- **Legal Disputes** (爭點): The main legal issues being argued
- **Court Opinion** (法院見解): The judge's reasoning and legal analysis
- **Case Results** (判決結果): The final outcome and ruling

**How it helps**:
- Target specific aspects of cases that matter most to your research
- Adjust the importance of each field based on your needs
- Get more precise results by focusing on relevant case sections

**Example**: When researching employment law, you might weight "Legal Disputes" heavily to find cases with similar workplace conflicts, while giving less weight to "Case Results" if you're more interested in the legal arguments than the outcomes.

### 3. Smart Workspace Management

**What it does**: Organizes your research projects into separate workspaces, keeping your searches and findings organized.

**Key Features**:
- Create up to 5 different research projects (tasks)
- Each workspace saves your search history automatically
- Switch between projects without losing your progress
- Track which cases you've reviewed and added to your research

**How it helps**:
- Keep different legal matters separate and organized
- Resume research exactly where you left off
- Share specific workspaces with colleagues or clients

**Example**: You might have one workspace for "Contract Law Research," another for "Employment Disputes," and a third for "Property Rights Cases."

### 4. Comprehensive Case Analysis

**What it does**: Provides detailed information about each case in an easy-to-understand format.

**Information Provided**:
- **Case Summary**: Key facts and background
- **Legal Issues**: Main points of dispute
- **Court's Reasoning**: How the judge analyzed the case
- **Final Decision**: What the court ruled and why
- **Related Laws**: Specific legal statutes referenced
- **Case Details**: Court name, date, case number

**How it helps**:
- Quickly understand case relevance without reading full documents
- Identify patterns across similar cases
- Find specific legal precedents and citations

### 5. Relevance Scoring System

**What it does**: Shows you how closely each search result matches your query with visual indicators.

**Features**:
- Overall relevance percentage for each case
- Individual scores for different case sections
- Color-coded indicators for easy scanning
- Ranking from most to least relevant

**How it helps**:
- Focus on the most relevant cases first
- Understand why certain cases were selected
- Make informed decisions about which cases to review in detail

### 6. Intelligent Document Generation

**What it does**: Automatically generates professional legal documents by combining your input with selected case precedents.

**Document Types Supported**:
- **起訴狀 (Complaint)**: Civil lawsuit initiation documents
- **答辯狀 (Defense)**: Response and defense documents
- **上訴狀 (Appeal)**: Appeal documents for higher courts
- **聲請狀 (Motion)**: Various legal motions and applications

**Input Fields**:
- **Basic Information**: Document type, case number, court, date
- **Party Information**: Plaintiff/defendant details, addresses, ID numbers
- **Case Content**: Case title, facts, legal basis, requests
- **Supporting Evidence**: Selected case precedents, attachments

**How it helps**:
- Generate professional legal documents automatically
- Ensure proper legal formatting and structure
- Incorporate relevant case precedents seamlessly
- Save hours of manual document drafting

### 7. Integrated Research-to-Document Workflow

**What it does**: Connects case search results directly to document generation with a seamless workflow.

**Key Features**:
- **Case Selection**: Add relevant cases from search results to document generation
- **Data Completeness Tracking**: Visual indicators showing required information status
- **Real-time Preview**: See document generation readiness as you input data
- **Floating Progress UI**: Convenient progress tracking that follows you as you work

**How it helps**:
- Streamline the entire legal research and drafting process
- Ensure no important cases are missed in document preparation
- Maintain consistency between research findings and final documents

### 8. Search History and Progress Tracking

**What it does**: Keeps track of all your searches and research progress automatically.

**Features**:
- Complete history of all searches performed
- Saved results for each query
- Progress indicators during searches
- Ability to revisit and refine previous searches
- Case selection persistence across sessions

**How it helps**:
- Build on previous research without starting over
- Track your research methodology
- Demonstrate thorough case law review for legal briefs
- Maintain selected cases for document generation

## Workflow

### Getting Started

#### Step 1: Account Setup and Login
1. Create your account using email and password
2. Log into the platform through the secure login page
3. Your personal dashboard will load automatically

#### Step 2: Create Your First Workspace
1. The system automatically creates your first research workspace
2. Give it a meaningful name (e.g., "Contract Dispute Research")
3. You can create up to 5 different workspaces for different projects

### Basic Search Process

#### Step 3: Choose Your Search Method
**Option A: Simple Search (一般搜尋)**
- Best for: Quick searches and general research
- Use when: You have a straightforward question or topic
- Example: "breach of contract cases"

**Option B: Multi-Field Search (多欄位搜尋)**
- Best for: Detailed research requiring precision
- Use when: You need to focus on specific aspects of cases
- Example: Searching for employment disputes where you care most about the legal arguments

#### Step 4: Enter Your Search Query

**For Simple Search**:
1. Type your question or topic in plain language
2. Click the search button or press Enter
3. Wait for results to load (usually 10-30 seconds)

**For Multi-Field Search**:
1. Switch to "Multi-Field Search" mode
2. Fill in the relevant fields:
   - **Case Content**: General topic or keywords
   - **Legal Disputes**: Specific legal issues you're researching
   - **Court Opinion**: Types of legal reasoning you're interested in
   - **Case Results**: Specific outcomes you want to find
3. Adjust field weights if needed (optional)
4. Click search

#### Step 5: Review Search Results
1. Results appear ranked by relevance
2. Each result shows:
   - Case title and basic information
   - Relevance score and indicators
   - Brief summary of key points
   - Court and date information

#### Step 6: Analyze Individual Cases
1. Click on any case to view detailed information
2. Review the organized sections:
   - **Summary**: Quick overview of the case
   - **Disputes**: Main legal issues
   - **Court Opinion**: Judge's reasoning
   - **Results**: Final ruling
   - **Related Laws**: Applicable statutes

#### Step 7: Manage Your Research
1. Mark important cases for your research
2. Add relevant cases to your document generation queue
3. Switch between different sections using the tab system
4. Use the workspace switcher to move between different projects

### Document Generation Process

#### Step 8: Select Relevant Cases for Document Generation
1. **Review Search Results**: Examine cases found through your searches
2. **Add to Document Generation**: Click "加入到文件生成" (Add to Document Generation) for relevant cases
3. **Case Management**: Selected cases appear in the document generation area
4. **Remove if Needed**: Remove cases that are no longer relevant

#### Step 9: Complete Document Information
1. **Switch to Input Tab**: Click "輸入" (Input) tab to access document generation
2. **Fill Basic Information**:
   - Document type (起訴狀, 答辯狀, 上訴狀, 聲請狀)
   - Case number, court, date
3. **Enter Party Information**:
   - Plaintiff/applicant details (name, ID, address)
   - Defendant/respondent details (name, ID, address)
4. **Describe Case Content**:
   - Case title and facts
   - Legal basis and relevant statutes
   - Specific requests or claims
5. **Review Supporting Materials**:
   - Selected case precedents appear automatically
   - Add additional attachments if needed

#### Step 10: Generate Legal Document
1. **Data Completeness Check**: System shows which sections are complete
2. **Generate Document**: Click "生成文件" when all required fields are filled
3. **Review Generated Document**: AI combines your input with case precedents
4. **Download or Copy**: Save the generated document for use

### Advanced Features

#### Refining Your Search
1. **Adjust Field Weights**: In multi-field search, use sliders to emphasize certain aspects
2. **Modify Queries**: Edit your search terms based on initial results
3. **Combine Methods**: Use insights from one search to inform another

#### Organizing Results
1. **Workspace Management**: Keep different legal matters in separate workspaces
2. **Search History**: Review and build upon previous searches
3. **Progress Tracking**: Monitor your research coverage and completeness
4. **Case Selection Management**: Track which cases are selected for document generation

#### Document Generation Features

2. **Floating Progress UI**: Convenient progress indicator that follows your work
3. **Case Integration**: Selected cases automatically incorporated into documents
4. **Professional Formatting**: Generated documents follow proper legal formatting standards

#### Quality Assurance
1. **Relevance Checking**: Use the scoring system to verify result quality
2. **Cross-Reference**: Compare similar cases to ensure comprehensive coverage
3. **Documentation**: Keep track of your search methodology for legal briefs

## Technical Architecture and Data Flow

### Frontend Components
- **WorkspaceView.vue** (`src/views/WorkspaceView.vue`): Main application interface with tab navigation
- **SearchModule.vue** (`src/components/SearchModule.vue`): Case search functionality with dual-mode support
- **FormInput.vue** (`src/components/FormInput.vue`): Document generation interface with data input forms
- **LogDisplay.vue** (`src/components/LogDisplay.vue`): Real-time search progress tracking

### Data Flow Process
1. **Search Phase**: User queries → API calls → Search results with relevance scores
2. **Selection Phase**: User selects relevant cases → Database updates with `added_to_doc_gen` status
3. **Input Phase**: User fills document information → Real-time validation and progress tracking
4. **Generation Phase**: Combined user input + selected cases → LLM processing → Generated document

### Database Schema
- **tasks**: User workspaces/projects with status tracking
- **search_results**: Search queries, results, and case selection status
- **case_2**: Legal case database with multi-field embeddings

### State Management
- **workspace.ts** (`src/store/workspace.ts`): Task management, search persistence, case selection
- **auth.ts** (`src/store/auth.ts`): User authentication and session management

### API Integration
- **Multi-field Search**: `https://wtlee328-multi-field-search-api.hf.space/multi-field`
- **General Search**: `https://wtlee328-multi-field-search-api.hf.space/new-search`
- **Document Generation**: TODO - LLM integration for document generation

interface CaseItem {

```typescript
interface DocumentData {

  }

```
